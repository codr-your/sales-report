# 销售报表生成脚本（考题一）

读取 `sales_raw.xlsx`，完成数据清洗与统计分析，输出 `report.xlsx`（4 个工作表）。

## 环境要求

- Python 3.10+
- pandas、openpyxl（测试另需 pytest）

```bash
pip install pandas openpyxl pytest
```

## 文件结构

```
sales_report/
├── sales_raw.xlsx        # 样例数据（含脏数据，由脚本生成）
├── make_sample_data.py   # 生成样例数据脚本（可复现）
├── main.py               # 主脚本：清洗 + 统计 + 输出报表
├── tests/
│   └── test_report.py    # pytest 测试（10 个用例）
├── requirements.txt
└── README.md
```

## 快速开始

```bash
# 1. 生成样例数据（首次或想重置数据时）
python make_sample_data.py

# 2. 一键运行生成报表
python main.py
# 输出：清洗前 14 行 -> 有效 7 行；月度总额：6420.00；报表已生成：report.xlsx

# 3. 自定义输入/输出文件
python main.py -i 其它数据.xlsx -o 结果.xlsx
```

## 报表结构（report.xlsx）

| 工作表 | 内容 | 列 |
|---|---|---|
| 明细清洗后 | 清洗后的有效记录 | 日期、销售员、产品、数量、单价、地区、销售额 |
| 按销售员 | 按销售员汇总 | 销售员、销售额（降序） |
| 按地区 | 按地区汇总 | 地区、销售额（降序） |
| 总览 | 月度汇总 | 月度总额、有效记录条数 |

## 清洗规则

1. 删除任一关键字段缺失的行（6 个字段均为关键字段）；
2. 剔除数量 ≤ 0 的行；
3. 按全部字段去重，保留首次出现。

## 异常处理（不崩溃、有中文提示）

| 场景 | 提示 |
|---|---|
| 文件不存在 | 未找到输入文件：xxx |
| 表头缺失/不匹配 | 表头不匹配，缺少字段：xxx |
| 文件为空 | 文件 xxx 为空，无任何数据 |
| 清洗后无有效数据 | 清洗后无有效数据，不生成报表 |
| 数量/单价非数值 | 按缺失处理（视作缺失行剔除） |
