# 考题一 · 需求澄清清单（定稿）

## 1. 任务目标

编写一个 Python 脚本，读取团队每月的销售原始表 `sales_raw.xlsx`，完成数据清洗与统计分析，输出标准化报表 `report.xlsx`。脚本须一键运行，无需人工干预。

## 2. 输入定义

- **文件名**：`sales_raw.xlsx`（与本脚本置于同一目录）
- **工作表**：默认读取第一个工作表，表头位于第 1 行
- **字段（6 列，顺序固定）**：日期、销售员、产品、数量、单价、地区
- **数据类型**：日期为日期格式；数量、单价为数值；销售员、产品、地区为文本
- **数据特点**：存在三类脏数据——空值（任意字段可能缺失）、重复行（整行完全相同）、异常数量（数量 ≤ 0）

## 3. 处理规则

### 3.1 清洗（按以下顺序执行）

1. 删除任一字段为空的行（6 个字段均为关键字段，缺一不可）；
2. 剔除数量 ≤ 0 的行；
3. 按全部 6 个字段去重，保留首次出现的行。

### 3.2 统计口径

- 单条销售额 = 数量 × 单价；
- 按销售员汇总销售额；按地区汇总销售额；
- 月度总额 = 全部有效记录销售额之和；
- 金额保留 2 位小数。

## 4. 输出定义

输出文件 `report.xlsx`，含 4 个工作表：

| 工作表 | 内容 | 列 |
|---|---|---|
| 明细清洗后 | 清洗后的全部有效记录 | 日期、销售员、产品、数量、单价、地区、销售额 |
| 按销售员 | 按销售员汇总 | 销售员、销售额（按销售额降序） |
| 按地区 | 按地区汇总 | 地区、销售额（按销售额降序） |
| 总览 | 月度汇总 | 月度总额、有效记录条数 |

## 5.边界与验收标准

### 5.1 异常处理（不崩溃、有可读提示）

- 文件不存在 → 提示"未找到 sales_raw.xlsx"并退出；
- 表头缺失或不匹配 → 提示字段格式错误并退出；
- 文件为空 / 无有效数据 / 清洗后 0 条记录 → 提示"无有效数据"并退出（不生成空报表）；
- 数量、单价为非数值 → 按缺失处理并提示。

### 5.2 验收标准（逐条核对）

- [x] 明细清洗后工作表与手工核对一致：无空值行、无数量≤0 行、无重复行；
- [x] 按销售员、按地区、月度总额三项统计数值与人工核算完全一致；
- [x] 原文件 sales_raw.xlsx 内容未被修改；
- [x] 文件缺失、空文件、无有效数据三种异常场景均给出明确中文提示且不崩溃。
